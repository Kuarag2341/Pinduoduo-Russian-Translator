# Русский демо-магазин

Отдельное демонстрационное Android-приложение для Samsung Galaxy S23+ и других
устройств Android 6.0+. Это визуальная демонстрация работы существующих
Localization Core и Android AAR, а не клиент Pinduoduo.

## Что демонстрирует

- Каталог тестовых товаров, локальный поиск, карточку товара и корзину в памяти
  приложения.
- Переключение между китайским и русским языками с сохранением выбора через
  `AndroidLocalization` из AAR.
- Вызовы `AndroidI18nAdapter` для переводов из существующих словарей и отдельного
  демонстрационного каталога.
- Fallback на переданный китайский текст, если ключ отсутствует.
- Постоянную заметную пометку «Демонстрация — тестовые данные».

Строки `demo.*` и товары в этом модуле являются только демонстрационными. Они не
добавляются к подтверждённому словарю Pinduoduo и не имитируют интеграцию с
оригинальным APK.

## Сетевые и коммерческие функции

Приложение не объявляет разрешение INTERNET и не содержит WebView, API-клиента,
авторизации, серверной корзины, оформления или оплаты. Поиск и корзина работают
только с четырьмя встроенными тестовыми товарами. Никакие запросы к Pinduoduo
не выполняются.

## Сборка и установка

Откройте папку `pinduoduo-localizer/android-integration` в Android Studio,
синхронизируйте Gradle и выберите конфигурацию `demo-app`. Debug APK собирается
командой:

```sh
./gradlew :demo-app:assembleDebug
```

Путь к APK:

```text
demo-app/build/outputs/apk/debug/demo-app-debug.apk
```

Установка на подключённое устройство:

```sh
adb install -r demo-app/build/outputs/apk/debug/demo-app-debug.apk
```

Параметры: `applicationId com.replit.pinduoduo.localizer.demo`, `minSdk 23`,
`targetSdk 35`, Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3.
