# Android integration module

Самостоятельный Android Library Module для существующего Kotlin-модуля
`pinduoduo-localizer`. Он подключает исходники ядра и словари по относительным
путям Gradle, не копируя их и не изменяя APK.

## Состав

- `localizer-android/` — Android-библиотека (`compileSdk 35`, `minSdk 23`).
- `AndroidAssetTranslationCatalog` — читает общие `i18n/ru` и `i18n/zh` из assets.
- `AndroidLocalization` — хранит выбор `ru`/`zh` в `SharedPreferences` и вызывает
  существующее ядро перевода.
- `AndroidI18nAdapter` — переводит исходную строку либо строковый ресурс,
  переданный хост-приложением.
- `WebViewI18nAdapter` — локальный интерфейс поиска для будущего мостика хостового
  WebView. Он сам не подключается к WebView и не создаёт JavaScript-интерфейс.
- `demo-app/` — отдельный Android-магазин с тестовыми товарами, который вызывает
  библиотеку. Он не подключается к Pinduoduo и не обращается к его серверам,
  аккаунтам, заказам или оплате.

## Сборка и тесты

Нужны JDK 17+, Android SDK 35 и Gradle 8.9. В корне этого проекта:

```sh
./gradlew :localizer-android:assembleDebug
./gradlew :localizer-android:testDebugUnitTest
```

При установленном Gradle 8.9 без wrapper команда эквивалентна:

```sh
gradle -p pinduoduo-localizer/android-integration \
  :localizer-android:assembleDebug \
  :localizer-android:testDebugUnitTest
```

## Граница интеграции

Это библиотека и проверяемые адаптеры, а не подключение к Pinduoduo. Для
интеграции нужны разрешённые исходники хост-приложения: вызов
`AndroidI18nAdapter` в точках получения текста и явное решение, какие ключи
использовать. Для WebView потребуются исходники хоста и его собственный
безопасный мост; этот модуль не внедряется в страницы Pinduoduo и не меняет
их DOM. Авторизация, платежи, серверная логика, APK и механизмы защиты не
затрагиваются.

## Демонстрационное приложение

Откройте этот каталог в Android Studio, выберите конфигурацию `demo-app` или
соберите debug APK командой:

```sh

```

Подробности, идентификатор приложения и путь к APK находятся в
[`demo-app/README.md`](demo-app/README.md).
## Статус официальной поддержки Pinduoduo

В доступных материалах проекта не найдено официальной документации Pinduoduo
для сторонних языковых пакетов, регистрации локали или изменения языкового
переключателя. `provenance.properties` сопоставляет локальные ключи с именами
строковых ресурсов из декодированного APK 8.31.0; это сведения о происхождении
текста, а не официальный манифест языкового пакета или контракт расширения.
Пока не предоставлены разрешённые исходники Pinduoduo либо официальная
документация, поддержку русского языка со стороны Pinduoduo подтвердить нельзя.

Поверхности, поддерживаемые только этой библиотекой:

- `LocaleCode` регистрирует локальные коды `ru` и `zh`.
- `AndroidLocalization.selectLanguage(tag)` принимает поддерживаемый тег
  (`ru`, `ru-RU`, `zh` или `zh-CN`) и сохраняет выбор в настройках приложения.
- Пользовательский переключатель языка остаётся ответственностью хост-приложения;
  официальная точка интеграции с переключателем Pinduoduo не установлена.

Эти интерфейсы не означают поддержку сторонних пакетов самим Pinduoduo и не
служат основанием для изменений его APK.
