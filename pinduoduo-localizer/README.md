# Pinduoduo Localizer Core

Изолированный Kotlin/JVM-модуль русификатора. Он содержит локальные словари
`ru`/`zh`, выбор языка, поиск по уникальному ключу, форматирование параметров и
fallback на исходный китайский текст.

Это не исходники Pinduoduo, не патч APK и не Android-приложение. Оригинальный
APK не используется модулем. Код пока не подключён к браузеру или приложению.

## Структура

- `src/main/kotlin/.../DictionarySection.kt` — список разделов словаря.
- `TranslationCatalog.kt` — чтение секционных UTF-8 `.properties`.
- `LocalizationModule.kt` — выбор языка, поиск, безопасное форматирование и fallback.
- `AndroidI18nAdapter.kt` — тонкий адаптер для будущих Android resource keys.
- `WebViewI18nAdapter.kt` — тонкий адаптер для `module` / `key` / `defaultValue`.
- `src/main/resources/i18n/{ru,zh}/` — словари по разделам: главная, поиск,
  категории, товары, характеристики, корзина, избранное, профиль, заказы,
  доставка и системные сообщения.
- `src/main/resources/i18n/provenance.properties` — имя исходного Android-ресурса
  APK для каждой подтверждённой записи.
- `AUDIT.md` — итоги сверки, исключённые строки и разделы без данных.
- `src/test/kotlin/.../LocalizationModuleTest.kt` — проверки переключения и
  fallback, разделов, UTF-8 и форматных параметров.

Каталог `zh` является исходным китайским текстом и резервным значением. Русский
каталог содержит только строки, точно сопоставленные с ресурсами APK 8.31.0.
Разделы характеристик и корзины оставлены пустыми: подтверждённые подписи в
проверенных офлайн-ресурсах не найдены.

## Запуск тестов

Нужны JDK 17+ и Maven:

```sh
mvn -f pinduoduo-localizer/pom.xml test
```

Тестируется только JVM-модуль. Android Gradle-проект и APK не собираются.

## Будущая интеграция

В отдельной разрешённой Android-сборке `AndroidI18nAdapter` можно вызвать из
обёртки над Android I18n при запросе строки по имени ресурса. Для WebView
`WebViewI18nAdapter.getText(module, key, defaultValue)` соответствует будущему
локальному пути моста. Пока это чистые Kotlin-интерфейсы без Android SDK,
JavaScript-инъекций, сети и зависимости от внутренних классов Pinduoduo.

При отсутствии ключа или пустом переводе возвращается переданный оригинальный
текст; если вызывающий код передал пустую строку, используется китайское
значение из каталога. `format` сохраняет исходный шаблон, если перевод содержит
несовместимые форматные спецификаторы. Перевод динамических произвольных текстов,
товаров и отзывов здесь пока не реализован: для них потребуется отдельный
локальный источник переводов.
